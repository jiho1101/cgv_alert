# CGV 공급자 검토용 패치

이 패치는 `hmmhmmhm/daiso-mcp`의 공개 소스 `513142141f17df0feb887070c957c0f3e7f6a4f0`에 적용하는 초안입니다. 공급자의 MIT 라이선스가 적용됩니다. 외부 이슈나 PR로 전송하지 않았고 공급자 운영 서버에 배포하지 않았습니다.

`queryMode=theater-only&theaterCode=0128&playDate=20261218`을 명시하면 극장별 원본 작업만 수행합니다. 기존 기본 요청의 영화 목록·개별 영화 폴백은 바꾸지 않습니다. 원본 작업이 실패하면 기존 오류를 그대로 반환합니다. 원본 작업이 유효한 빈 배열을 반환한 경우에만 `queryMode: theater-only`, `observation: empty_unconfirmed`를 반환합니다. 이것은 예매 미오픈이나 현재 감시 성공의 증거가 아닙니다.

목적은 실패한 optional 폴백과 실제 극장별 원본 오류를 분리해 확인하는 것입니다. 현재 운영 502가 어느 단계에서 발생하는지는 아직 관측되지 않았습니다. 따라서 이 패치가 운영 장애를 해결했다고 주장하지 않습니다.

적용 후 검증할 실제 요청은 다음과 같습니다.

1. 0128 / 20261028: 실제 영화·회차·총좌석·잔여좌석이 기존 기본 요청과 일치해야 합니다.
2. 0128 / 20261102 및 20261218: 원본 실패는 오류를 유지해야 하고, 유효한 빈 배열은 명시적인 미확정 관측이어야 합니다.
3. 응답에 `queryMode: theater-only`가 없으면 새 모드가 반영됐다고 보지 않습니다. 인식되지 않은 쿼리를 기존 서버가 무시할 수 있기 때문입니다.

로컬 타입 검사는 통과했습니다. 로컬 테스트는 공급자 보호 실행기의 `ps` 자원 관측 실패 때문에 실행하지 않았습니다. 우리 저장소의 격리된 GitHub CI 40596095913에서 동일한 보호 실행기로 전체 회귀를 실행했습니다. 339개 테스트 파일에서 4,171건 통과·1건 건너뜀, Statements/Branches/Functions/Lines 모두 100%를 확인했습니다. 타입 검사와 공개 도구 10개 계약도 통과했습니다. 공급자 운영 배포·실제 미래 날짜 응답 검증은 남아 있습니다.
